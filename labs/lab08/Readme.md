# Lab 8: Projectile in JavaScript

This page ports my Lab 7 physics engine to JavaScript and draws it on an HTML5 canvas. It animates a projectile launched at 20 m/s and 50 degrees with a fading trail and a live HUD that shows t, x, y, |v|, KE, PE and E_total. To run it, open the lab08 folder in VS Code, right-click index.html, and choose Open with Live Server. The controls include the Scene menu (Part A coordinate test, projectile, or a spring oscillator), the Integrator menu (Euler-Cromer or Velocity Verlet), the Timestep menu (fixed with an accumulator, or variable using the frame time, toggled with the T key), the DT menu (1/240, 1/120, 1/60 or 1/20 s), and the buttons Relaunch (R), Pause (P), Lag spike (L, a 300 ms stall) and Run headless. Run headless, or typing runHeadless() in the Console, runs 1200 steps of DT = 1/120 with no rendering and prints the final x, y, vx, vy and E_total at full precision.
